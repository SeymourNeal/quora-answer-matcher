# Contributing

Thank you for contributing to Quora Answer Matcher.

## Before opening a pull request

- Keep changes focused on one outcome.
- Do not commit secrets, API keys, user answers, or copied Quora content.
- Add or update tests when application behavior changes.
- Explain the user-facing impact in the pull request description.

## Product principles

- Human review before any use of a suggested result
- Respectful use of public web-search results
- Clear explanations for every match score
- No automated activity on Quora

## Reporting issues

Please include the expected behavior, actual behavior, reproduction steps, and any safe-to-share example text.
